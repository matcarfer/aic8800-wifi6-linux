# Contributing

**English** · [Español](CONTRIBUTING.es.md)

- **It worked on your distro?** Open an issue with the "It works!" template so it goes into the tested table.
- **It failed?** Run `diagnose.sh` and open an issue with the "It didn't work" template.
- **Driver bugs** (drops, speed, crashes after install) belong upstream: [shenmintao/aic8800d80](https://github.com/shenmintao/aic8800d80/issues).
- **Pull requests:** small and explained. Messages in both languages (`t 'es' 'en'`), `bash -n` and `shellcheck -S warning` clean. See [AGENTS.md](AGENTS.md).
