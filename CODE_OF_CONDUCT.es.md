# Código de conducta

[English](CODE_OF_CONDUCT.md) · **Español**

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/). Su texto completo es la referencia.

En resumen:

- Sé amable y paciente. Mucha gente llega frustrada porque no le anda el WiFi, y muchas personas recién empiezan con Linux.
- Nada de acoso, insultos ni ataques personales o políticos. No publicar datos privados de otras personas.
- Se critican el código y las ideas, nunca a las personas.
- Escribí en castellano o en inglés; los dos son igual de bienvenidos.

Quienes mantienen el proyecto pueden editar o borrar comentarios, issues y PRs que rompan estas reglas, y bloquear a quien las rompa de forma repetida.

**Para reportar:** escribile en privado por GitHub a quien mantiene el proyecto, [@matcarfer](https://github.com/matcarfer). Los reportes se tratan con confidencialidad.
